【プロジェクト概要】
・pygameを用いて作成したシンプルなチェスのゲームです。
・アンパッサン、キャスリング、プロモーションを実装しています。
・このゲームで利用される画像はすべて手作りのものです。

【動作】
・windows11での動作のみを確認済。

【公開物説明】
・「local_exe」「local_src」「cpu_exe」「cpu_src」があります。
・「local_XXX」は一つの画面を２人で操作してゲームをします。
　exeの方は実行のみを目的としたフォルダで、srcの方はソースコードが格納されています。
・「cpu_XXX」は、「local_XXX」の黒側をCPUにしたものです。
　グリード法を用いたCPUと対戦可能です。
　exeの方は実行のみを目的としたフォルダで、srcの方はソースコードが格納されています。

【使い方（exe）】
・「XXX_exe」フォルダの中に格納されている「main.exe」をダブルクリックすることで実行されます。
